# PodeTelar v0.1.3

This release brings hardware-only codec compatibility, a simpler sharing sidebar,
a centered update changelog, and the Apple Silicon macOS app.

## Changes

- Streams choose AV1 → HEVC → H.264 from the sender's hardware encoders and every
  connected room member's hardware decoders, including members using previews.
  Software decoder availability does not count as compatibility.
- Missing frames, interruptions, mute and network stalls no longer blacklist
  working codecs or trigger a switch to H.264. A compatible live codec also stays
  selected after a restrictive member leaves. Start or Apply can select the
  preferred codec again.
- Native admission announces hardware capabilities before entering the media room,
  avoiding a temporary H.264-only assumption during joins. Everyone in the room
  needs a client with the updated capability declaration before a new stream can
  start; missing older declarations remain pending.
- The sharing sidebar is simpler. Update availability opens a centered changelog
  with explicit Download, Later and Restart controls. Restart ends sharing and
  watching before updating; it never resumes media automatically.
- Application identifiers, invitations and documentation now consistently use
  PodeTelar. Room links use `podetelar://`; owned legacy protocol registrations are
  removed while other applications' handlers are preserved.
- Apple Silicon macOS builds use ScreenCaptureKit, hardware VideoToolbox codecs,
  native audio output and a separate macOS updater channel. AV1 receive requires
  hardware support; AV1 encoding on macOS is unavailable.

## Installation and updates

Windows users should download **PodeTelar-v0.1.3-Setup.exe**. Existing v0.1.2
installations can use the built-in updater. Versions 0.1.0 and 0.1.1 need one
manual Setup upgrade because their launchers were built without an update feed.
Upgrade older clients before using the renamed invitation protocol and the new
hardware compatibility declarations.

Apple Silicon users should download the macOS disk image attached to this release.
Screen & System Audio Recording permission is required for capture. The macOS
package uses its own `osx-arm64` updater feed; Windows retains the `preview` feed.

Public assets include installers, full update packages, platform feeds, manifests
and checksums. Portable Windows EXEs and intermediate ZIPs remain internal.
Earlier releases and their assets are preserved.

## Qualification limits

Windows remains an unsigned preview; macOS uses ad hoc signing. Checksums verify
integrity and do not independently authenticate the publisher. Local Windows
media validation uses NVIDIA hardware and synthetic sources. Existing Apple
Silicon results do not establish every M-series chip or macOS version.
Fresh-machine/offline behavior, AMD, real-game/group/WAN performance, physical
display/speaker synchronization and 4K120 are not newly qualified by this release.
See [Windows distribution](../distribution.md), [Windows updates](../windows-updates.md)
and [macOS qualification](../macos.md) for the validation scope and remaining work.
