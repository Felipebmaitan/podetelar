# Round 1 — finding validation before implementation

Validated against application source `3432929`, the current native-renderer captures,
and the controller/SDK paths. Gemini's Antigravity provider lacked native computer
use. Its interaction-specific scores remain unverified; the numeric scores are
supplemental static opinions, not a completed usability gate.

| Finding                                                              | Validation                                                                                                                                                                                                                                 | Decision                                                                                                                                   |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Hidden local identity / no non-sharing presence                      | Confirmed: `PublisherUi::sharing_menu` hides name after joining; the header never renders it. `Snapshot` exposes stream tiles but no general participant list.                                                                             | Show the joined identity and room presence from existing SDK state. No new server API is needed.                                           |
| No cancel while joining / Forget in Advanced                         | Confirmed in the UI. **The suggested button-only fix is insufficient:** `worker` awaits `Session::join`, so a queued `Command::Leave` cannot preempt it.                                                                                   | Add actual join cancellation and cleanup, then expose Cancel and room/session options.                                                     |
| Mixed dropdown widths / labels / default styling                     | Confirmed in `quality_controls`, `bitrate_controls` and Advanced: mixed `from_label`/stacked labels and missing full-width settings. Styling criticism is subjective, not proof of a functional defect or contrast violation.              | Standardize controls and apply a coherent native theme. Measure/verify readability separately.                                             |
| Low-position errors / unlabeled busy / raw status / no copied notice | Confirmed by the render order and lack of copy feedback state.                                                                                                                                                                             | Keep actionable feedback visible outside the scrolling settings panel; label busy operations and copy confirmation.                        |
| Preview/live ambiguity / tall watched controls / four-tile clipping  | Badges and compact playback controls are missing. The four-stream capture clips the lower card edges, but **scrolling already exists**: this is fit/density friction, not proof that lower streams are inaccessible.                       | Add explicit state badges, compact controls, and adaptive tile sizing while preserving 16:9 video and explicit subscriptions.              |
| Apply enabled without edits / missing bitrate                        | Unchanged Apply is confirmed. **Reject the main-panel bitrate recommendation:** Felipe explicitly requested bitrate and codec remain in Advanced.                                                                                          | Track active requested settings, disable unchanged Apply and describe live versus restart changes. Keep bitrate diagnostics in Advanced.   |
| Enter/Escape / small targets / labels                                | Explicit form-submit and exit-focus shortcuts are absent. That does **not** establish that existing egui keyboard navigation is broken; hands-on behavior is untested. Small secondary buttons and unlabeled custom bitrate are confirmed. | Add clear shortcuts, label associations and larger targets; verify actual keyboard/accessibility behavior before claiming a passing score. |

No proposed remediation is accepted solely because it appeared in the review.
The implementation pass will record its changes and validation by category.
