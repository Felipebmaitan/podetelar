# PodeTelar v0.1.2

This installer enables the built-in update controls. The app checks the public
PodeTelar GitHub releases feed on startup and periodically. Download and restart
remain explicit actions. Hover over the update button for release notes; choose
Later to keep using the current version. Restart to update ends sharing/watching
and does not automatically rejoin a room or resume media.

**One-time manual upgrade:** v0.1.0 and v0.1.1 were built without an update feed,
so their missing update button cannot be repaired remotely. Install the new Setup
once; subsequent compatible updates can use the built-in download/restart flow.

Release assets include Setup, the full update package, the preview-channel feed,
an installer manifest and checksums. The full package/feed support the updater;
users installing manually should choose Setup. Portable builds remain internal.
Published v0.1.0/v0.1.1 assets are preserved.

This remains an unsigned Windows x64 installer preview. Feed hashes check package
integrity and do not independently authenticate the publisher. Development-PC
qualification does not establish fresh-PC/offline behavior, physical A/V timing,
AMD or physical 4K120 support. See [update rollout](../windows-updates.md) for the
verification scope and remaining acceptance work.
