Inter is copyright 2020 The Inter Project Authors and distributed under the
SIL Open Font License 1.1. See [OFL-Inter.txt](OFL-Inter.txt). The application code
remains MIT licensed. The font license is embedded and viewable in Room options;
portable distributions also include `notices/Inter-OFL.txt`.

Source: <https://github.com/google/fonts/tree/main/ofl/inter>.
`Inter-Variable.ttf` is the original `Inter[opsz,wght].ttf` from that directory.
The bundled static faces are instantiated with fontTools 4.63 at optical size 14,
weights 400 and 600. Static instantiation avoids relying on renderer support for
variable font weight. The font binaries retain the upstream copyright metadata.
