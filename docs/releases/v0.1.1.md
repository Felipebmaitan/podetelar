# PodeTelar v0.1.1

Windows x64 maintenance release with clearer stream controls and improved native
playback and codec compatibility.

## Changes

- Native WebRTC audio playback is now the default, with per-stream volume/mute
  and automatic recovery when the Windows output endpoint changes or returns.
- Rooms adapt AV1 → HEVC → H.264 using the sender's available hardware, selected
  encoder preference and connected members' decoders. Compatible rooms can return
  to the preferred codec when restrictions leave.
- Advanced settings applies changed live stream settings when you select Apply
  and close. Bitrate choices include Automatic, 6–100 Mbps presets and Custom;
  the custom input appears only when selected and remains capped at 100 Mbps.
- Stream information separates reception, network/decoding and sender values,
  with collapsed details and clear stale/unavailable measurements.
- Repaired the sidebar settings gear, aligned room names beside the logo, removed
  the redundant SDR label and translated the legacy Friends placeholder in PT-BR.
- Discord /stream and /telar name each new room for the person running the command.
- Administrator usage aggregates the same PC across room sessions while keeping
  device recognition separate from room admission and authentication.

## Installation and limits

Download **PodeTelar-v0.1.1-Setup.exe** from the GitHub release. Run Setup for a
per-user installation or upgrade with shortcuts and invitation links. Existing
standalone users can migrate using Setup. Verify SHA256SUMS and the installer
manifest. Public assets contain only Setup, its manifest and checksums; the
portable payload remains internal to the installer.

This is an **unsigned Windows preview**. Its internal installer version has a
preview build suffix, and the public automatic update feed stays disabled.
Current validation is on the development Windows PC with NVIDIA hardware.
No new AMD, fresh-PC/offline, physical 4K120, physical display/speaker sync,
real-game/group-performance, signed-delivery or production media-update
qualification is claimed. The release manifest records actual source and artifact
verification; existing measurement limitations remain in the verification docs.
