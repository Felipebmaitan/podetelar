# PodeTelar v0.1.4

## Discord and rooms

- Sign in with Discord from the desktop app. PodeTelar opens your system browser
  and remembers the connection using your operating system's credential storage.
- Join the same PodeTelar room as friends in a supported Discord voice channel.
  Changing channels ends the previous stream and subscriptions before joining
  the next room. Sharing and watching start when you choose them.
- Join through an invitation to stay connected independently of Discord voice.
  Voice channels can have reusable guest invitations. When you run `/stream` or
  `/telar` while in voice, the bot returns the channel invitation privately.
- Signed-in participants use their Discord server nickname when it is available.
  Guests can edit their nickname and add a profile picture, including an animated
  GIF up to 3 MB. The app remembers the last guest nickname on the device.
- The administrator dashboard organizes guest profiles, Discord bot status,
  channel rooms, invitations and account management into separate sections.

## Install and update

Windows users can use the built-in updater or download
**PodeTelar-v0.1.4-Setup.exe**. Apple Silicon users can use the macOS updater or
download the disk image. Windows packages are unsigned and macOS packages use
ad hoc signing.
